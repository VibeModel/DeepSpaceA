# 深空自动化局 / Deep Space Automation

一款**增量 / 自动化放置类（incremental / idle）游戏**：从手动采矿起步，逐步搭建「矿→钢→零件→信用点」的自动化生产链；再解锁**铜链**（铜矿→铜材→电路板/合金→蓝图），用「加工建筑 + 配方配比」把产线像 Factorio 那样盘活，并通过科技、自动化与**「重构」**不断放大效率。

中后期在这之上再叠三层长期目标：**无限层巨型结构「星门」**（吃全链产物，永久加成）、**第二层「升华」**（换取跨层保留的**星图**与分支升级）、以及让每一局都不一样的**随机事件**（自动结算）与**合同**（手动交付、在线倒计时）。整体是可持续**无限滚服**的形态。

- 技术栈：**Vite + TypeScript**，无框架，手写 DOM 渲染
- 纯逻辑与 UI 分离，核心逻辑有单元测试覆盖
- 暗色科幻主题，中英双语界面

---

## 快速开始

需要 Node.js 18+。

```bash
npm install       # 安装依赖
npm run dev       # 启动本地开发服务器（含调试面板）
npm run build     # 类型检查 + 生产构建，输出到 dist/
npm run preview   # 预览生产构建
npm test          # 运行核心逻辑测试（tsx）
```

打开开发服务器给出的地址即可开始游戏。

## 玩法介绍

### 目标与核心循环

1. **手动采矿** → 攒「铁矿」
2. **出售矿石** → 换「信用点」
3. **用信用点建造/升级建筑** → 自动生产、加工、研究
4. **用研究点解锁科技** → 提升产量、解锁自动化与**新配方**
5. **调配加工建筑的配方配比** → 让熔炉在炼钢/炼铜之间分台数，打通铜链
6. **合成「蓝图」** → 购买蓝图专属永久升级（跨轮保留）
7. **本轮峰值收入达到阈值后「重构」** → 换取跨轮保留的 Core Data 与永久升级
8. **用全链产物建造「星门」** → 无限层、永久提升全局产量 / 供电、降低建筑成本
9. **累计核心数据足够后「升华」** → 重置一层，换取跨层保留的「星图」与分支升级

在此过程中，**随机事件**（自动出现、限时增益/减益）与**合同**（手动接单、在线倒计时、交付换信用点）会持续提供短期决策。

一句话：**手动启动 → 自动化 → 配方取舍 → 指数增长 → 重构 / 星门 / 升华层层变强 → 无限滚服**。

| 🧱 合金 Alloy | 装配机（合金冶炼：钢材×2 + 铜材×1） | 蓝图合成、星门建造、出售 |
| 📘 蓝图 Blueprints | 装配机（蓝图合成：电路板 + 合金） | 购买蓝图永久升级（**跨轮保留**） |
| ⚡ 电力 Power | 初始着陆模块 + 太阳能阵列 | 全建筑耗电；不足则全产线按比例降速 |
| 💠 核心数据 Core Data | 重构 | 购买永久升级 |
| 🌌 星图 Stellar Charts | 升华 | 购买第二层星图升级（**跨层保留**） |

**出售价**：铁矿 1 / 钢材 4 / 零件 12 / 铜材 10 / 电路板 40 / 合金 80 —— 加工越深越值钱，鼓励打通整条产线。铜链资源自阶段 A 起**也可出售**（原先只能熬成蓝图，是个死胡同），因此「卖掉换现金」还是「继续加工」成为真实的取舍。规范源：`SELLABLE_RESOURCES` 与 `SELL_PRICES`。

出售方式有两种：**逐个出售**（建筑面板中的单一资源按钮，或快捷键 `W/E/R/T/Y/U`），以及**一键出售全部**（建筑面板的 💰 按钮或快捷键 `X`），后者一次性清空所有可售资源库存。两者共用同一套价格规则与**市场乘数**（受「市场繁荣 / 供给过剩」等事件影响），逻辑入口分别为 `sellResource` 与 `sellAllResources`。

> 电力不是可储存的资源，而是**供需流量**：见下方「电力（Power）」。

### 建筑与产线

建筑按顺序解锁（**下游建筑需要先拥有 1 台上游建筑**），成本按 `基础价 × 增长率^已有数量` 增长。

| 建筑 | 类型 | 作用 |
|---|---|---|
| ⛏ 铁矿钻机 | 采集 | 自动产出铁矿 |
| ☀ 太阳能阵列 | 电力 | 为全基地供电（拥有首台铁矿钻机后解锁） |
| 🔶 铜矿钻机 | 采集 | 自动产出铜矿（拥有熔炼炉后解锁） |
| 🔥 熔炼炉 | 加工 | 按配比执行 **钢铁冶炼 / 铜矿冶炼** |
| ⚙ 制造厂 | 加工 | 按配比执行 **零件制造 / 电路制造** |
| 🛠 装配机 | 加工 | 按配比执行 **合金冶炼 / 蓝图合成**（拥有制造厂后解锁） |
| 🔬 实验室 | 科研 | 消耗信用点 → 产出研究点 |

**PRODUCTION 面板**实时显示每个环节的产出速率、利用率、输入/产能/效率与瓶颈提示（缺料 / 积压），以及电力供需条。

### 配方系统（Recipes）

加工建筑（熔炼炉 / 制造厂 / 装配机）不自带固定的「输入→输出」，而是**一台机器 + 一组配方配比**，灵感来自 Factorio 的配方路线：

| 配方 | 机器 | 配方 | 速度 | 解锁科技 |
|---|---|---|---|---|
| 🔥 钢铁冶炼 | 熔炼炉 | 铁矿 ×1 → 钢材 ×1 | 1.0 批/s | 无（默认） |
| 🔶 铜矿冶炼 | 熔炼炉 | 铜矿 ×1 → 铜材 ×1 | 0.8 批/s | 铜矿冶炼 |
| ⚙ 零件制造 | 制造厂 | 钢材 ×1 → 零件 ×1 | 0.5 批/s | 无（默认） |
| 🔬 电路制造 | 制造厂 | **铜材 ×2 + 零件 ×1** → 电路板 ×1 | 0.4 批/s | 电路制造 |
| 🧱 合金冶炼 | 装配机 | **钢材 ×2 + 铜材 ×1** → 合金 ×1 | 0.3 批/s | 合金合成 |
| 📘 蓝图合成 | 装配机 | **电路板 ×1 + 合金 ×1** → 蓝图 ×1 | 0.15 批/s | 合金合成 |

**按台数分配（关键）**：每台机器都可以把**台数**按权重拆给多个配方，而不是二选一。在建筑卡片上用 `− / +` 调整各配方的权重，卡片会显示该配方当前分到的**台数**：

- 例：20 台熔炼炉配成 `钢铁冶炼 3 : 铜矿冶炼 1` → **15 台炼钢、5 台炼铜**，两条产线同时运行。
- 之所以不是「二选一」：电路需要铜材 **且** 需要零件，若熔炉只能在钢/铜之间二选一，电路就永远造不出来。
- 全 0（或未设置）时回退到该机器的**默认配方满额运行**；被科技锁住的配方会被忽略（重构后科技清空，配比会安全回退）。
- **多输入批次上限**：一批需要多种原料时，本 tick 的批次数取 `min(设计产能, 各原料库存/单批用量)` —— 因此「缺铜材」与「缺零件」都会让电路产线降速，面板会指出到底卡在哪一种原料上。
- 配方配比存放在 `GameState.recipeMix`，**每轮重构后重置为默认**。

### 电力（Power）

**每座建筑都耗电**，电力是瞬时供需（无储能）：

- **供给** = 初始着陆模块 `15` + 每台太阳能阵列 `6`（受「电网优化」科技加成）。
- **需求** = 各建筑数量 × 各自耗电（铁矿钻机 0.15 / 铜矿钻机 0.2 / 熔炼炉 0.6 / 制造厂 1.2 / 装配机 2.4 / 实验室 2.0）。
- 当**需求 > 供给**时，全基地按 `供给 / 需求` **按比例降速**（采矿、加工、实验室一并受影响）。
- PRODUCTION 面板的电力条会变琥珀并显示百分比；此时星球场景转为预警色，各环节诊断行也会追加 `⚡ 电力 x%` 以说明降速原因（避免误判为缺料）。

> 太阳能阵列的**供电不随里程碑翻倍**，长期靠「电网优化」科技与更多阵列扩张。

### 里程碑

每种建筑在拥有 **10 / 25 / 50 / 100 台**时，产量 **×2**（可叠加，最高 ×16）。这是前期最主要的产量跃升来源。（电力供给不享受此加成。）

### 科研（科技树）

- 3 条分支：**工业工程 / 自动化 / 计算**（多数为线性前置，允许分支，如「电网优化」从「自动熔炼」分出）。
- 科技分两类：
  - **解锁型 / 功能型**：一次性购买，解锁自动出售、自动购买、生产分析等；**工业工程**分支末端还有 3 项**配方解锁**（铜矿冶炼 → 电路制造 → 合金合成），逐级打开铜链。
  - **数值型（10 个）**：购买后可**无限升级**。每级效果线性叠加（如采矿 `×(1 + 0.5×等级)`），成本按 `基础价 × 1.5^等级` **指数增长** —— 效果线性、成本指数，形成天然的收益递减与软上限。
- **自动科研**：解锁「自动科研」科技后，可在自动化页开启，自动购买可负担的科技（优先"解锁型"，其次最便宜的"无限升级"）。
- 科技等级在每次**重构后重置**（属于本轮内成长）。

### 自动化

解锁对应科技后，在 **AUTOMATION 面板**开启：

- **自动出售**：自动出售超过储备线的多余资源（铁矿/钢材/零件各自可开关）
- **自动购买**：信用点超过某建筑当前价格 1.5 倍时自动购买（每帧最多 5 台）
- **自动科研**：自动购买可负担的科技

### 成就（纯荣誉）

打开底部标签栏的 **🏆 成就** 页面查看。共 **22 项**，覆盖首台建筑、累计产量、信用点、科研数量、里程碑、电网规模、游玩时长，以及铜链（首份铜矿 / 首块电路板 / 首块合金 / 首份蓝图）等维度。

- **纯荣誉**：不提供任何数值加成，只作为进度见证。
- 每项由「一个单调递增的指标 vs 目标值」判定，未解锁时显示实时进度条。
- 达成后会弹出提示，并**跨重构永久保留**（存在 `GameState.achievements`）。

### 生产分析（数值诊断）

解锁「生产分析」科技后，FLOW 的每个阶段都会显示诊断行。FLOW 面板按 **阶段** 展示（采集 2 段 + 6 个配方段 + 科研段，未解锁 / 未建造的阶段自动隐藏），加工段标题形如「🔥 熔炼炉 · 钢铁冶炼」，例如：

```
⛏ 铁矿采集 Ore Mining          下游需求 20.0/s · 铁矿不足
🔥 熔炼炉 · 钢铁冶炼            利用率 100% · 铁矿盈余 12.0/s · 建议 +3 台
⚙ 制造厂 · 电路制造             利用率 45% · 铜材缺口 · 上游不足 · 需 零件 2.0/s
🔬 科研 Research               ⚠ 信用点不足，实验室停机
```

其中「建议 +N 台」直接告诉你该补多少台机器来消除瓶颈；多输入配方会额外列出副原料的消耗速率。

### 蓝图与蓝图升级（Blueprints）

铜链的最终产物是**蓝图**——一种**跨轮保留**的第二货币，也是新产线的长期回报：

- 只有**装配机**能合成蓝图（电路板 + 合金各 1），速度很慢（0.15 批/s），因此需要把装配机台数在「合金冶炼 / 蓝图合成」之间分配。
- 蓝图在顶栏有独立读数（解锁铜链前隐藏），并在**重构页的「蓝图升级」区块**消费：

  | 升级 | 效果 | 可否无限升级 |
  |---|---|---|
  | 🔶 铜矿开采强化 | 铜矿采集 +25%/级 | ✅ |
  | 🔬 电路超频 | 电路与合金 **加工速度** +25%/级 | ✅ |
  | 🧱 合金精通 | 合金与蓝图 **产出** +20%/级 | ✅ |
  | 🛠 装配机预置 | 重构开局获得 1 台装配机（每级 +1） | ✅ |

- 蓝图**不随重构清零**（与 Core Data 一样属于元进度）；而 `recipeMix` 配比与铜链资源都会在重构时重置。

### 重构（Prestige）与永久升级

- 当**本轮峰值收入（credits/s）达到 50**（阈值 `PRESTIGE_THRESHOLD_CPS`）时即可重构。
- 重构会**重置**：全部资源（含铜矿/铜材/电路板/合金）、建筑、科技（含无限升级）、配方配比、区域等级、**事件与合同**；**保留**：核心数据、**蓝图**、永久升级、统计、**星门 / 星图**。
- 获得的核心数据按**本轮峰值收入**计算：`⌊√(本轮峰值 credits/s / 5) × 收益加成⌋`。
  - 「本轮峰值」是 run 级字段 `runPeakCreditsPerSec`，每次模拟取当帧 `net.credits` 的最大值，随重构**归零**。
  - 因此**每一轮都凭自己的表现兑付**，勤于重构不再吃亏（旧的「累计信用增量」模型下，同一天花板重复重构拿不到任何新收益）。推得越高，一次重构的收益越大。
- 注意：核心数据**只在重构时结算**，不会因为买升级而减少「已领取额度」——额度与消耗是两个独立的量。
- **永久升级**（用 Core Data 购买，跨轮保留）：
  | 升级 | 效果 | 可否无限升级 |
  |---|---|---|
  | 🚀 快速启动 | 每轮开局获得铁矿钻机（+2/级） | ✅ |
  | 🧠 工业记忆 | 所有生产效率 +20%/级 | ✅ |
  | 🛰 自动物流 | 开局即解锁自动出售 | ❌ 一次性 |
  | 🗄 研究档案 | 研究产量 +25%/级 | ✅ |

  重构页的永久升级区会**实时显示当前持有的 Core Data**，方便对照每项升级的价格（购买后立即扣减并刷新）。另有 4 项用**蓝图**购买的升级，见「蓝图与蓝图升级」。

### 星门（Stargate，无限层巨型结构）

打开底部标签栏的 **🌀 星门** 页面。星门是本作的**长线目标阶梯**，也是「无限滚服」的核心：

- **每级吃全链产物**：`钢材 2000 · 零件 1200 · 电路板 600 · 合金 300`（规范源 `STARGATE_INPUTS` / `STARGATE_BASE_COST`），必须**四种同时备足**才能整级原子支付（不足一种就建不了）。
- **成本指数增长**：第 `n` 级成本 = `基础价 × 1.18ⁿ`（每种输入相同倍率）。因此前期几级轻松，后面必须靠更深的产线自动化推。
- **永久加成**（跨重构、跨升华保留）：
  - 全局产量 `×(1 + 0.03n)`
  - 电网供电 `×(1 + 0.01n)`
  - 所有建筑成本 `×0.99ⁿ`
- **命名里程碑**：达到 T1 / 5 / 10 / 25 / 50 / 100 / 200 时，各再获得一次**额外的 ×1.5 产量**（可叠加），让无限层也有清晰的「章节感」（初阶星门 → 稳定虫洞 → 星门阵列 → 量子中继 → 跨星系门 → 银河枢纽 → 深空灯塔）。层级**没有上限**。
- 星门的降本**单独**乘进 `buildingCost`（`buildings.ts` 的成本不走 `computeModifiers`），而产量/供电走 `computeModifiers`，两条路径都已接线。

### 第二层：升华（Ascension，星图）

当**累计核心数据 ≥ 50** 时可以升华。这是比重构更高一层的重置：

- **重置**：核心数据、永久升级（若持有「记忆回溯」则保留 25%）、以及整轮进度（同重构）。
- **保留**：星门层级、星图、星图升级、成就、统计、累计核心数据。
- 升华获得 **星图（Stellar Charts）**：`⌊(⌊√(累计核心数据 / 2)⌋ − 已领取额度) × 星图加成⌋`。用的是累计值与「已领取额度」的**增量**，防止在同一累计值上反复刷取。

**星图升级**（跨层保留的分支树，8 项）：

| 升级 | 效果 | 类型 |
|---|---|---|
| 🏭 工业星图 | 所有生产效率 +20%/级 | 无限 |
| 💰 经济星图 | 所有建筑成本 ×0.96/级 | 无限 |
| 💠 重构星图 | 一层重构收益 +10%/级 | 无限 |
| 🗺 星图星图 | 升华获得的星图 +10%/级 | 无限 |
| 🌀 星门星图 | 星门建造成本 ×0.95/级 | 无限 |
| 📜 合同星图 | 同时进行的合同槽位 +1/级 | 无限 |
| 🔄 自动重构 | 解锁「自动重构」（本轮峰值达阈值即自动重构） | 一次性 |
| 🧠 记忆回溯 | 升华时保留 25% 的永久升级等级 | 一次性 |

> 无限项的造价按 `基础价 × 1.7^等级` 增长；一次性项价格固定、买过即满级。

### 随机事件（Events，自动结算）

打开任意页面时，顶部会出现**事件条**，显示当前生效的事件与倒计时。

- **只在你重构（或升华）过至少一次后出现**（门槛 `prestigeCount ≥ 1 || ascensionCount ≥ 1`），因此新档完全不受影响。
- 事件按**模拟时间**推进（与生产同一时钟，**含离线分块结算**），每个事件持续约 60 秒，每隔约 180 秒（带抖动）有概率刷出一个；同时不会出现重复事件。
- 全部为**乘算修正**，折入统一修正器：正产出（富矿脉 / 市场繁荣 / 研究突破 / 太阳耀斑）与负产出（离子风暴 / 供给过剩）。
- **每轮重构清零**（事件属于「本轮」的短期状态）；PRNG 种子 `rngSeed` 跨轮保留，因此**同一存档的事件流可复现**（也避免靠读档刷新好运）。

### 合同（Contracts，手动交付）

打开底部标签栏的 **📜 合同** 页面。合同是外部的**限时订单**：

- 同样在**首次重构后**解锁。
- 订单要求你在**在线时间内**交付一定数量的某种资源，完成即得信用点，**奖励 = 货值 × 1.5**（高于直接出售）。
- 订单量与奖励**随你本轮的产量缩放**：只会向你**正在生产**的资源下单，数量约为「交付窗口内产量的 40%」，因此任务总是可达成的。
- 有两种计时（都只走**在线墙钟时间**，离线不推进、也不会过期）：
  - **接单窗口**：订单出现后约 240 秒内需接受，否则消失；
  - **交付倒计时**：接受后 600 秒内交付，逾期作废（无惩罚）。
- 同时可接的槽位为基础 `2`，由「合同星图」提升。
- **每轮重构清零**：订单随本轮产能重置。

> 事件用**模拟时间**（会自动结算、离线也推进），合同用**在线墙钟时间**（纯手动）——这是两者设计上刻意的差异。

### 星球与区域（Planets & Regions）

打开底部标签栏的 **🪐 星球** 页面：这是与「建筑 / 科技」并列的**第二条成长轴**。

**星球**：每颗星球带一组全局修正，本次整轮都生效。

| 星球 | 修正 | 解锁条件 |
|---|---|---|
| 🌍 母星 Homeworld | 无（均衡） | 始终 |
| ⛏ 铁锈星 Ferrum | 采矿 ×1.6、供电 ×0.75 | 重构次数 ≥ 1 |
| 🔥 熔火星 Pyra | 熔炼 ×1.5、建筑成本 ×1.15 | 重构次数 ≥ 3 |
| 🔬 冰寒星 Cryon | 研究 ×1.8、全局产量 ×0.9 | 累计核心数据 ≥ 80 |

- 切换星球的**唯一方式是重构**：在星球页选定「下次重构目的地」，下次重构后整轮就在该星球上重建。
- 之所以不随时可切，是为了避免「挖矿时切富矿星、研究时切高研究星」的绕过取舍；选择落在跨轮保留的 `nextPlanet`，只在重构时落地到本轮。
- **解锁不落存档**：由 `prestigeCount` / `lifetimeCoreData`（本就跨轮保留）**纯派生**计算；新解锁的星球会弹出提示。

**区域**：当前星球上有若干**可升级区域**，用**信用点**升级，提供产量 / 电力 / 研究加成；等级上限 20，成本按 `基础价 × 增长率^等级` 增长，**每轮重构后清零**。

| 区域 | 效果 | 适用星球 |
|---|---|---|
| ⛏ 采矿场 | 采矿 +15%/级 | 通用 |
| 🔥 冶炼区 | 熔炼 +12%/级、钢材产出 +5%/级 | 通用 |
| 🔌 电网枢纽 | 供电 +10%/级 | 通用 |
| 🔬 科研园区 | 研究 +15%/级 | 母星、冰寒星 |
| 📦 物流中枢 | 全局产量 +4%/级 | 铁锈星、熔火星 |

- 区域既可在星球页升级，也可直接点击**生产面板星球场景上的热点按钮**升级（按钮显示当前等级，满级/买不起会有对应样式）。
- 星球与区域的修正会折入统一的修正器（`computeModifiers`），因此生产、电力、成本、重构收益全部自动受益。

### 离线收益

关闭页面后重新打开，会按离线时长结算产出，上限 **24 小时**，并弹出「欢迎回来」汇总。

### 界面与响应式

采用**两栏布局**（左：建筑；右：上方生产、下方统计）+ 顶部**事件条**（有事件时才显示）+ 底部标签栏（科研 / 自动化 / 合同 / 星门 / 重构 / 星球 / 数据 / 成就 / 设置）。生产与统计同处右列纵向堆叠，避免统计栏单独占一列显得空旷。窗口尺寸自适应：

- **宽屏**：两栏并排（右列内部上下堆叠）。
- **中屏 / 平板**：收为单栏纵向堆叠。
- **手机**：进一步压缩间距与字号；触控设备（`pointer: coarse`）的按钮放大到 ≥44px 便于点击。

### 存档

- **存档格式**：JSON 信封 `{ version, timestamp, state }`，当前 `version = 5`，写入浏览器 `localStorage`（键名 `deepspace_automation_save`）。
- **自动存档**：每 20 秒写入一次；此外在**购买科技 / 永久升级 / 星图升级、调整配方配比、选择星球/升级区域、重构、升华、建造星门、接受/交付合同、导入存档、关闭页面**时立即保存。
- **手动归档**：底部「📤 导出存档 / 📥 导入存档」按钮。
  - 导出：生成 Base64 文本，复制粘贴即可备份。
  - 导入：粘贴文本覆盖当前进度。**旧存档会自动迁移**：
    - 缺失字段回填默认值（迁移只合并默认对象中**已存在**的键，因此新增字段会自动带上默认值）；
    - 旧版本中布尔型的科技 / 永久升级会转为等级数字；
    - `planet` / `nextPlanet` / `regions` 在老存档中回填为母星 / 母星 / 全 0，且会校验星球 id（非法回退母星）并钳制区域等级到 `[0, 20]`；
    - **v3 新增**：`blueprints`（缺省 `0`）、`recipeMix`（缺省为默认配比）、以及铜链统计（缺省 `0`）。配比会被**规整**：未知/越界的配方 id 丢弃、权重取非负整数。
    - **v4 新增**：`runPeakCreditsPerSec`（缺省 `0`）、星门 / 第二层字段（`stargateLevel / stellarCharts / lifetimeStellarCharts / chartsGranted / ascensionCount / rngSeed`）。其中 `stellarUpgrades` 是 `Record`，读档时用**穷举默认 map** `emptyStellarUpgradeMap()` 补齐全部键，否则旧档该整段会丢失。旧的 `prestigeGranted` 字段被移除（一层收益已改绑本轮峰值）。
    - **v5 新增**：`activeEvents` / `eventSpawnIn`（随机事件，run 级）与 `contractOffers` / `activeContracts` / `contractSpawnIn` / `nextContractId`（合同，run 级）。读档时会**逐条校验**：事件 id 必须在 `EVENTS` 中、合同资源必须属于 `SELLABLE_RESOURCES`，否则丢弃；数值字段统一钳制。
  - 所有新增的 run 级字段都会被 `freshRunState()` 赋默认值，因此**重构 / 升华**会把事件与合同一并清空。
- ⚠️ Base64 只是编码不是加密，存档可被随意编辑（单机游戏无妨）。

### 大数值说明

游戏使用 JS `number`（双精度）。为避免无限增长导致 `Infinity/NaN` 破坏存档：

- 全局上限 `MAX_VALUE = 1e18`，超出即封顶（不会清零）。
- 科技等级上限 1000、建筑数量上限 100 万、区域等级上限 20，从源头抑制指数爆炸。
- 每帧对资源、建筑、等级、星球 / 区域、Core Data、蓝图、星图、星门层级、星图升级等级、配方配比、**事件与合同**、速率（含逐配方指标）、统计做安全钳制。

### 数字显示格式（设置页）

打开底部标签栏的 **⚙ 设置**，可在三种数字格式间即时切换（设置页含实时预览）：

| 格式 | 示例 | 说明 |
|---|---|---|
| 后缀缩写 | `1.23K` / `1.23M` / `1.23Dc` | 默认。每 3 个数量级进一级；超出后缀表时自动退化为科学计数法 |
| 科学计数法 | `3.30e211` | 3 位有效数字，任意量级统一样式 |
| 工程计数法 | `33.0e210` | 指数恒为 3 的倍数，尾数 1–999 |

- 三种格式对 `|值| < 1000` 的小数一律显示为普通数字（如 `42`、`3.5`）。
- 选择会写入独立的 `localStorage` 键 `deepspace_ui_settings`，**不随游戏存档重置/重构而被清空**。
- 相关实现：`src/ui/format.ts`（格式化）、`src/ui/settings.ts`（偏好持久化）。

### 星球场景与动态反馈

生产面板顶部是一颗**由数值驱动的星球**（纯 CSS 绘制，无外部资源）：

- **亮度/呼吸**：总吞吐越高，星球越亮、呼吸（缩放脉冲）越快；开局是暗淡缓慢的微光。
- **基地光点**：行星表面的光点随**建筑总数**点亮，越多越密。
- **轨道与光环**：建成熔炼炉/制造厂/装配机后出现外层轨道与第二颗卫星；任一建筑达到 25 台解锁行星光环。
- **护航船队**：有运输船沿轨道环飞行，**数量随建筑总数增加**（最多 10 艘），基地越繁忙飞得越快。
- **瓶颈预警**：解锁「生产分析」后，任一配方缺料或上游积压时星球辉光转为琥珀色脉冲。
- **流动与脉冲**：生产流水线有按各阶段速率变化的扫光与箭头脉冲；资源读数按盈亏方向做绿/红呼吸；顶栏 Credits 随收入脉冲；购买建筑会弹跳、达到里程碑/解锁新系统会有一次庆祝。

**基地天际线（COLONY BELT）**：星球场景正下方是一条按**建筑类型**分组的「天际线」，共 7 组（每种建筑一组），把「你造了多少」直接画出来：

- **塔数** = 该建筑跨过的**里程碑层级 + 1**（达到 10 / 25 / 50 / 100 台时各多长出一座塔，最多 5 座）。
- **塔高** = 该建筑的**拥有数量**（对数缩放，`nodeScale = 250` 前持续增长），因此后期也能看出差异。
- **标签** = 精确数量；未建造的建筑组自动变暗，建造后点亮。
- **窗口闪烁** = 该组建筑数量越多闪得越快；同时**建筑卡片本身**会在「确实在产出」时呼吸发光（`data-busy`），脉冲速度与天际线同一条曲线。
- 相关常数在 `src/ui/visual.ts` 的 `VISUAL`（`towerPool` / `towerMinH` / `towerMaxH` / `nodeScale` / `nodePulse*`），塔数用的里程碑层级直接取自 `balance.ts` 的 `MILESTONES`，与玩法里程碑**同源**。

打开 **⚙ 设置 → 动画** 可在 **中等·生动 / 克制 / 关闭** 三档间即时切换（同样持久化在 `deepspace_ui_settings`）：

- **关闭**：停掉全部场景 / 数字动画（状态颜色保留）。
- **克制**：保留静态星球与天际线，但停掉闪烁、扫光、护航船与卡片呼吸。
- 尊重系统的「减少动态效果」偏好（`prefers-reduced-motion`），此时一律静止。
- 动画参数由 `src/ui/visual.ts` 的纯函数从实时数值映射（`tanh`/`log` 归一化，避免后期数值饱和），JS 仅每 180ms 低频写入 CSS 变量，动画由 CSS 完成；数量相关的 DOM 只在数值真正变化时才被触碰。
