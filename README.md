# 深空自动化局 / Deep Space Automation

一款**增量 / 自动化放置类（incremental / idle）游戏**：从手动采矿起步，逐步搭建「矿→钢→零件→信用点」的自动化生产链，通过科技、自动化与「重构」不断放大效率。

- 技术栈：**Vite + TypeScript**，无框架，手写 DOM 渲染
- 纯逻辑与 UI 分离，核心逻辑有单元测试覆盖
- 暗色科幻主题，中英双语界面

---

## 快速开始

需要 Node.js 18+。

```bash
npm install       # 安装依赖
npm run dev       # 启动本地开发服务器（含调试面板）
npm run build     # 类型检查 + 生产构建，输出到 dist/
npm run preview   # 预览生产构建
npm test          # 运行核心逻辑测试（tsx）
```

打开开发服务器给出的地址即可开始游戏。

## 玩法介绍

### 目标与核心循环

1. **手动采矿** → 攒「铁矿」
2. **出售矿石** → 换「信用点」
3. **用信用点建造/升级建筑** → 自动生产、加工、研究
4. **用研究点解锁科技** → 提升产量、解锁自动化
5. **累计信用点达到阈值后「重构」** → 换取跨轮保留的 Core Data 与永久升级，进入下一轮滚雪球

一句话：**手动启动 → 自动化 → 指数增长 → 重构变强 → 重复**。

### 资源

| 资源 | 来源 | 用途 |
|---|---|---|
| ⛏ 铁矿 Ore | 手动采矿 / 采矿无人机 | 熔炼、出售 |
| 🔥 钢材 Steel | 熔炼炉消耗铁矿 | 制造、出售 |
| ⚙ 零件 Components | 制造厂消耗钢材 | 出售（售价最高） |
| 💳 信用点 Credits | 出售资源 | 购买建筑、支付实验室开销 |
| 🔬 研究点 Research | 实验室（消耗信用点） | 解锁 / 升级科技 |
| ⚡ 电力 Power | 初始着陆模块 + 太阳能阵列 | 全建筑耗电；不足则全产线按比例降速 |
| 💠 核心数据 Core Data | 重构 | 购买永久升级 |

出售价：铁矿 1 / 钢材 4 / 零件 12 —— 加工越深越值钱，鼓励打通整条产线。

> 电力不是可储存的资源，而是**供需流量**：见下方「电力（Power）」。

### 建筑与产线

建筑按顺序解锁（**下游建筑需要先拥有 1 台上游建筑**），成本按 `基础价 × 增长率^已有数量` 增长。

| 建筑 | 作用 |
|---|---|
| ⛏ 采矿无人机 | 自动产出铁矿 |
| ☀ 太阳能阵列 | 为全基地供电（拥有首台采矿无人机后解锁） |
| 🔥 熔炼炉 | 消耗铁矿 → 产出钢材 |
| ⚙ 制造厂 | 消耗钢材 → 产出零件 |
| 🔬 实验室 | 消耗信用点 → 产出研究点 |

**PRODUCTION 面板**实时显示每个环节的产出速率、利用率、输入/产能/效率与瓶颈提示（缺料 / 积压），以及电力供需条。

### 电力（Power）

**每座建筑都耗电**，电力是瞬时供需（无储能）：

- **供给** = 初始着陆模块 `15` + 每台太阳能阵列 `6`（受「电网优化」科技加成）。
- **需求** = 各建筑数量 × 各自耗电（无人机 0.15 / 熔炼炉 0.6 / 制造厂 1.2 / 实验室 2.0）。
- 当**需求 > 供给**时，全基地按 `供给 / 需求` **按比例降速**（采矿、熔炼、制造、实验室一并受影响）。
- PRODUCTION 面板的电力条会变琥珀并显示百分比；此时星球场景转为预警色，各环节诊断行也会追加 `⚡ 电力 x%` 以说明降速原因（避免误判为缺料）。

> 太阳能阵列的**供电不随里程碑翻倍**，长期靠「电网优化」科技与更多阵列扩张。

### 里程碑

每种建筑在拥有 **10 / 25 / 50 / 100 台**时，产量 **×2**（可叠加，最高 ×16）。这是前期最主要的产量跃升来源。（电力供给不享受此加成。）

### 科研（科技树）

- 3 条分支：**工业工程 / 自动化 / 计算**（多数为线性前置，允许分支，如「电网优化」从「自动熔炼」分出）。
- 科技分两类：
  - **解锁型 / 功能型**：一次性购买，解锁自动出售、自动购买、生产分析等。
  - **数值型（10 个）**：购买后可**无限升级**。每级效果线性叠加（如采矿 `×(1 + 0.5×等级)`），成本按 `基础价 × 1.5^等级` **指数增长** —— 效果线性、成本指数，形成天然的收益递减与软上限。
- **自动科研**：解锁「自动科研」科技后，可在自动化页开启，自动购买可负担的科技（优先"解锁型"，其次最便宜的"无限升级"）。
- 科技等级在每次**重构后重置**（属于本轮内成长）。

### 自动化

解锁对应科技后，在 **AUTOMATION 面板**开启：

- **自动出售**：自动出售超过储备线的多余资源（铁矿/钢材/零件各自可开关）
- **自动购买**：信用点超过某建筑当前价格 1.5 倍时自动购买（每帧最多 5 台）
- **自动科研**：自动购买可负担的科技

### 成就（纯荣誉）

打开底部标签栏的 **🏆 成就** 页面查看。共 **18 项**，覆盖首台建筑、累计产量、信用点、科研数量、里程碑、电网规模、游玩时长等维度。

- **纯荣誉**：不提供任何数值加成，只作为进度见证。
- 每项由「一个单调递增的指标 vs 目标值」判定，未解锁时显示实时进度条。
- 达成后会弹出提示，并**跨重构永久保留**（存在 `GameState.achievements`）。

### 生产分析（数值诊断）

解锁「生产分析」科技后，FLOW 各环节会显示诊断行，例如：

```
熔炼 Smelting        利用率 100% · 铁矿盈余 12.0/s · 建议 +3 熔炉
制造 Manufacturing   利用率 45% · 钢材缺口 2.0/s · 熔炼不足
科研 Research        ⚠ 信用点不足，实验室停机
```

其中「建议 +N 台下游」直接告诉你该补多少台下游建筑来消除瓶颈。

### 重构（Prestige）与永久升级

- 当**累计获得的信用点达到 500,000**（阈值）时即可重构。
- 重构会**重置**：资源、建筑、科技（含无限升级）；**保留**：核心数据、永久升级、统计。
- 获得的核心数据按**累计信用点**计算，但每次重构只发放「上次已领取额度之上」的**增量**：≈ `⌊(⌊√(累计信用 / 5000)⌋ − 已领取) × 加成⌋`。由于累计信用不会清零，**在同一天花板下重复重构不会产出新的核心数据**（按钮会显示「暂无新收益」），必须继续赚取信用点才能再获得。
- **永久升级**（用 Core Data 购买，跨轮保留）：
  | 升级 | 效果 | 可否无限升级 |
  |---|---|---|
  | 🚀 快速启动 | 每轮开局获得采矿无人机（+2/级） | ✅ |
  | 🧠 工业记忆 | 所有生产效率 +20%/级 | ✅ |
  | 🛰 自动物流 | 开局即解锁自动出售 | ❌ 一次性 |
  | 🗄 研究档案 | 研究产量 +25%/级 | ✅ |

  重构页的永久升级区会**实时显示当前持有的 Core Data**，方便对照每项升级的价格（购买后立即扣减并刷新）。

### 星球与区域（Planets & Regions）

打开底部标签栏的 **🪐 星球** 页面：这是与「建筑 / 科技」并列的**第二条成长轴**。

**星球**：每颗星球带一组全局修正，本次整轮都生效。

| 星球 | 修正 | 解锁条件 |
|---|---|---|
| 🌍 母星 Homeworld | 无（均衡） | 始终 |
| ⛏ 铁锈星 Ferrum | 采矿 ×1.6、供电 ×0.75 | 重构次数 ≥ 1 |
| 🔥 熔火星 Pyra | 熔炼 ×1.5、建筑成本 ×1.15 | 重构次数 ≥ 3 |
| 🔬 冰寒星 Cryon | 研究 ×1.8、全局产量 ×0.9 | 累计核心数据 ≥ 80 |

- 切换星球的**唯一方式是重构**：在星球页选定「下次重构目的地」，下次重构后整轮就在该星球上重建。
- 之所以不随时可切，是为了避免「挖矿时切富矿星、研究时切高研究星」的绕过取舍；选择落在跨轮保留的 `nextPlanet`，只在重构时落地到本轮。
- **解锁不落存档**：由 `prestigeCount` / `lifetimeCoreData`（本就跨轮保留）**纯派生**计算；新解锁的星球会弹出提示。

**区域**：当前星球上有若干**可升级区域**，用**信用点**升级，提供产量 / 电力 / 研究加成；等级上限 20，成本按 `基础价 × 增长率^等级` 增长，**每轮重构后清零**。

| 区域 | 效果 | 适用星球 |
|---|---|---|
| ⛏ 采矿场 | 采矿 +15%/级 | 通用 |
| 🔥 冶炼区 | 熔炼 +12%/级、钢材产出 +5%/级 | 通用 |
| 🔌 电网枢纽 | 供电 +10%/级 | 通用 |
| 🔬 科研园区 | 研究 +15%/级 | 母星、冰寒星 |
| 📦 物流中枢 | 全局产量 +4%/级 | 铁锈星、熔火星 |

- 区域既可在星球页升级，也可直接点击**生产面板星球场景上的热点按钮**升级（按钮显示当前等级，满级/买不起会有对应样式）。
- 星球与区域的修正会折入统一的修正器（`computeModifiers`），因此生产、电力、成本、重构收益全部自动受益。

### 离线收益

关闭页面后重新打开，会按离线时长结算产出，上限 **24 小时**，并弹出「欢迎回来」汇总。

### 界面与响应式

采用三栏布局（建筑 / 生产 / 统计）+ 底部标签栏（科研 / 自动化 / 重构 / 星球 / 成就 / 设置 / 统计）。窗口尺寸自适应：

- **宽屏**：三栏并排。
- **中屏 / 平板**：收为单栏纵向堆叠。
- **手机**：进一步压缩间距与字号；触控设备（`pointer: coarse`）的按钮放大到 ≥44px 便于点击。

| 键 | 作用 |
|---|---|
| `Q` | 手动采矿 |
| `A` `S` `D` `F` `G` | 依次购买 采矿无人机 / 太阳能阵列 / 熔炼炉 / 制造厂 / 实验室 |

### 存档

- **存档格式**：JSON 信封 `{ version, timestamp, state }`，当前 `version = 2`，写入浏览器 `localStorage`（键名 `deepspace_automation_save`）。
- **自动存档**：每 20 秒写入一次；此外在**购买科技 / 永久升级、重构、导入存档、关闭页面**时立即保存。
- **手动归档**：底部「📤 导出存档 / 📥 导入存档」按钮。
  - 导出：生成 Base64 文本，复制粘贴即可备份。
  - 导入：粘贴文本覆盖当前进度。**旧存档会自动迁移**：
    - 缺失字段回填默认值（迁移只合并默认对象中**已存在**的键，因此新增字段会自动带上默认值）；
    - 旧版本中布尔型的科技 / 永久升级会转为等级数字；
    - 本版新增的 `prestigeGranted`（已领取的重构额度）在老存档中按 `0` 处理 —— 因此老存档首次进入会**一次性补发**此前的累计核心数据额度，之后即受「增量发放」约束；
    - 本版新增的 `planet` / `nextPlanet` / `regions` 在老存档中回填为母星 / 母星 / 全 0，且会校验星球 id（非法回退母星）并钳制区域等级到 `[0, 20]`。
- ⚠️ Base64 只是编码不是加密，存档可被随意编辑（单机游戏无妨）。

### 大数值说明

游戏使用 JS `number`（双精度）。为避免无限增长导致 `Infinity/NaN` 破坏存档：

- 全局上限 `MAX_VALUE = 1e18`，超出即封顶（不会清零）。
- 科技等级上限 1000、建筑数量上限 100 万、区域等级上限 20，从源头抑制指数爆炸。
- 每帧对资源、建筑、等级、星球 / 区域、Core Data、速率、统计做安全钳制。

### 数字显示格式（设置页）

打开底部标签栏的 **⚙ 设置**，可在三种数字格式间即时切换（设置页含实时预览）：

| 格式 | 示例 | 说明 |
|---|---|---|
| 后缀缩写 | `1.23K` / `1.23M` / `1.23Dc` | 默认。每 3 个数量级进一级；超出后缀表时自动退化为科学计数法 |
| 科学计数法 | `3.30e211` | 3 位有效数字，任意量级统一样式 |
| 工程计数法 | `33.0e210` | 指数恒为 3 的倍数，尾数 1–999 |

- 三种格式对 `|值| < 1000` 的小数一律显示为普通数字（如 `42`、`3.5`）。
- 选择会写入独立的 `localStorage` 键 `deepspace_ui_settings`，**不随游戏存档重置/重构而被清空**。
- 相关实现：`src/ui/format.ts`（格式化）、`src/ui/settings.ts`（偏好持久化）。

### 星球场景与动态反馈

生产面板顶部是一颗**由数值驱动的星球**（纯 CSS 绘制，无外部资源）：

- **亮度/呼吸**：总吞吐越高，星球越亮、呼吸（缩放脉冲）越快；开局是暗淡缓慢的微光。
- **基地光点**：行星表面的光点随**建筑总数**点亮，越多越密。
- **轨道与光环**：建成熔炼炉/制造厂后出现外层轨道与第二颗卫星；任一建筑达到 25 台解锁行星光环。
- **瓶颈预警**：解锁「生产分析」后，产线失衡时星球辉光转为琥珀色脉冲。
- **流动与脉冲**：生产流水线有按各阶段速率变化的扫光与箭头脉冲；资源读数按盈亏方向做绿/红呼吸；顶栏 Credits 随收入脉冲；购买建筑会弹跳、达到里程碑/解锁新系统会有一次庆祝。

打开 **⚙ 设置 → 动画** 可在 **中等·生动 / 克制 / 关闭** 三档间即时切换（同样持久化在 `deepspace_ui_settings`）：

- 尊重系统的「减少动态效果」偏好（`prefers-reduced-motion`），此时一律静止。
- 动画参数由 `src/ui/visual.ts` 的纯函数从实时数值映射（`tanh`/`log` 归一化，避免后期数值饱和），JS 仅低频写入 CSS 变量，动画由 CSS 完成。

## 开发说明

- 开发构建（`npm run dev`）会显示一个**调试面板**，可快速加资源、加速时间、解锁内容；生产构建中该面板**完全不渲染**。
